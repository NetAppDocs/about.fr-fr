[[mcp-endpoint]]
== point de terminaison MCP

Le serveur MCP docs.netapp.com dispose d'un point de terminaison HTTP distant qui expose la documentation NetApp via une interface MCP standard. Les applications clientes telles que GitHub Copilot dans Visual Studio Code, Claude Desktop, Cursor et les frameworks d'agents Python personnalisés peuvent s'y connecter via un client MCP compatible.

.point de terminaison HTTP
`\https://docs.netapp.com/mcp`

Le format d'exemple suivant est utilisé pour configurer le serveur MCP à l'aide d'un  `mcp.json` fichier dans Visual Studio Code. Pour obtenir des informations sur les autres clients MCP pris en charge, consultez link:mcp-server-get-started.html["Commencez avec le serveur MCP docs.netapp.com"].

[source, json]
----
{
  "servers": {
    "netapp-docs-mcp": {
      "type": "http",
      "url": "https://docs.netapp.com/mcp",
      "headers": {
        "Ocp-Apim-Subscription-Key": "${input:Ocp-Apim-Subscription-Key}"
      }
    }
  },
  "inputs": [
    {
      "type": "promptString",
      "id": "Ocp-Apim-Subscription-Key",
      "description": "Enter your access key",
      "password": true
    }
  ]
}
----


[[tools]]
== Outils

Le serveur MCP de docs.netapp.com propose un ensemble d'outils restreint et ciblé pour la découverte et la récupération de documentation. Vous n'avez pas à spécifier d'outil lorsque vous invoquez le serveur MCP dans votre client. Le client IA choisit l'outil approprié en fonction de la requête.

Le serveur fournit actuellement les outils suivants :

* `netapp_docs_ask` : Génère des réponses dérivées du contenu publié sur docs.netapp.com à l'aide d'un flux de travail de génération augmenté par la récupération.
* `netapp_docs_search` : Découvre les pages de documentation NetApp pertinentes à l'aide de requêtes par mots-clés et en langage naturel.
* `netapp_docs_fetch`: Récupère le contenu structuré d'une page de documentation ou d'un article spécifique.
* `health_check`: Valide la disponibilité du serveur MCP.
